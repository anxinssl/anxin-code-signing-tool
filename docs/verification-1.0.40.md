## 完成的修改

- 补齐此前未提交的必要源码、运行资源和依赖锁文件。
- 独立初始化 Git 暂存区，不复制原仓库历史、私有日志、证书或客户截图文档。
- 补充敏感文件忽略规则、常见密钥模式扫描和二进制路径／哈希白名单。
- 将必要 UI 回归基线脱敏后纳入版本管理，解除对开发机私有证据目录的依赖。
- 卸载程序使用系统目录下的 `msiexec.exe`，打开文件夹使用 Windows 目录下的
  `explorer.exe`；不依赖当前目录或 PATH 搜索这两个系统程序。
- 补充中文入门教程、贡献说明、安全说明、许可证待确认说明及依赖许可证清单。
- 增补复制图标来源声明，静态测试同时核对图标来源与共享／内联画笔规则。
  固定版已有的状态图标和下拉箭头使用精确例外校验，不修改产品界面。
- 发布脚本显式使用 x64 平台；安装包必须包含并校验第三方声明文件，
  仍拒绝缺失声明、篡改文件及额外签名工具。
- 增加只读权限的 Windows CI 配置，默认只运行明确筛选的非签名检查。
  CI 配置尚未在 GitHub 上实际执行，本次验证来自本地。
