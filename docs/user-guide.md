# 安信代码签名证书工具使用教程

适用版本：1.0.44。

## 安装

在 Windows 10/11 x64 电脑上，运行 [Releases 页面](https://github.com/anxinssl/anxin-code-signing-tool/releases/latest)提供的 EXE 安装包，按照提示完成安装。安装包自带 .NET 运行时，无需额外安装 .NET SDK。

## 准备证书

- **云证书**：安装并登录对应客户端。例如，Certum 云证书使用 SimplySign Desktop；如需动态密码，从手机 App 获取当前有效密码。
- **硬件 UKey**：安装 SafeNet 等设备对应驱动，插入 UKey，确认客户端能够识别设备和证书。硬件用户无需额外安装 SimplySign。

需自行准备有效的代码签名证书，工具不附带证书。证书需具备代码签名用途、关联私钥，并能通过对应客户端或驱动完成调用。不同云服务、UKey 型号和驱动版本的兼容性以实际环境为准。

## 开始签名

1. **刷新证书**。打开工具，点击“刷新证书”。看到有效证书后选择主证书；没有证书时，检查客户端登录状态或 UKey 驱动及连接状态，再重新刷新。
2. **添加文件**。点击“添加文件”或“添加文件夹”，检查队列内文件是否正确。遇到不支持、失败、暂停或已取消的项目时，按提示重试或移除相应项目。
3. **选择模式**。通常使用单签；需要双签时，确认文件支持双签并选择符合要求的辅助证书。
4. **选择输出位置**。使用有写入权限的独立文件夹，输出目录不能与原文件位置相同。建议创建专用的“签名输出”文件夹。
5. **开始签名**。点击“签名”，等待队列处理完成。期间保持客户端会话或 UKey 连接，按证书客户端提示完成必要的认证。
6. **获取结果**。查看各文件的处理结果，打开输出目录获取签名后的文件。注意区分原文件与输出文件。

## 文件格式与模式

- EXE、DLL、OCX 等真实 PE 格式文件可以按工具判断使用单签或双签。
- MSI、CAB 在本工具中使用单签，不使用双签。
- 双签不仅需要文件格式支持，也需要符合要求的主证书和辅助证书。
- 文件扩展名不等于实际格式；其他格式和具体可用模式，以工具检测结果为准。

## 常见情况

**没有读取到证书**：确认云客户端已登录，或硬件驱动已识别 UKey，然后重新点击“刷新证书”。仅插入设备不代表驱动和证书已准备完成。

**签名按钮不可用**：依次检查是否已刷新并选择有效证书、文件是否可处理、签名模式是否匹配、双签辅助证书是否已选、输出目录是否已选择。

**文件无法保存**：请更换为有写入权限的独立输出目录。桌面或 C 盘并非一律不可用，实际权限和系统保护情况可能不同。

**时间戳失败**：检查网络和设置中的时间戳地址，不要将失败结果视为已经完整签名。

**需要帮助**：可通过软件内“联系技术支持”入口获取帮助。工具栏“更多”提供导出诊断和打开日志入口；分享诊断资料前请先脱敏。
