# 安信代码签名证书工具 1.0.44 使用教程

## 准备

在 Windows 10/11 x64 电脑上运行正式提供的安信代码签名证书工具 EXE 安装包。
如已安装旧 MSI 版，请先关闭工具，在 Windows 设置中卸载旧版，再运行新版安装包。
不要卸载 SimplySign，也不需要删除证书、原文件或输出文件。
如果 Windows 显示来源或权限提示，先确认安装包来自可信渠道，再继续安装。
客户不需要安装 .NET SDK。

按证书的使用方式准备：

- 云证书：安装并登录对应客户端。例如 Certum 云证书使用 SimplySign Desktop；
  如需动态密码，从手机 App 获取当前有效密码。
- 硬件 UKey：安装 SafeNet 等对应驱动，插入 UKey，确认客户端能够识别设备和证书。
  硬件用户不需要为了使用本工具额外安装 SimplySign。

本工具读取 Windows 个人证书库中有效、具备代码签名用途且关联私钥的证书。
不是所有硬件型号都已实测；证书能显示不代表实际私钥调用一定成功。

## 开始签名

1. **刷新证书。** 打开安信代码签名证书工具，点击“刷新”。看到有效证书后再继续；
   没有证书时，检查云客户端登录状态或 UKey 驱动及连接状态，再重新刷新。
2. **选择文件。** 点击“添加文件”或“添加文件夹”，检查队列内文件是否正确。
   队列里存在不支持、失败或取消的项目时，先按提示重试或移除相应项目。
3. **选择证书和模式。** 选择有效的主证书。通常使用单签；
   需要双签时选择“双签”，并选择符合要求的辅助证书。
   若软件提示文件不支持双签，改用单签。
4. **选择输出位置。** 开始签名前选择一个有写入权限的独立文件夹。
   输出位置不要与原文件位置相同。建议单独创建“签名输出”文件夹。
5. **开始签名。** 点击签名，等待队列处理完成。期间保持云客户端会话或 UKey 连接，
   按证书客户端提示完成必要的认证。
6. **取出文件。** 查看每个文件的处理结果，打开输出目录获取已签名文件。
   原文件与输出文件分开保存，不要把原文件误当作签名结果。

## 注意事项

- `.exe`、`.dll`、`.ocx` 等真实 PE 格式文件可以按软件判断使用单签或双签。
  文件扩展名不等于实际格式，重命名后缀不能改变签名能力。
- `.msi`、`.cab` 在本工具中使用单签，不使用双签。以当前界面的检测提示为准。
- 双签不仅需要文件格式支持，也需要合适的主证书和辅助证书；
  没有辅助证书时不要选择双签。
- 时间戳需要服务器可访问。发生时间戳错误时检查网络和设置中的时间戳地址，
  不要把失败结果视作已经完整签名。
- 桌面或 C 盘并非一律不能保存，但部分目录会受权限、系统保护或安全软件限制。
  若提示无法保存或无权限，请换到自己可写的输出文件夹后重试，
  不建议通过关闭安全软件或修改系统目录权限解决。
- 签名按钮不可用时，依次检查：证书是否刷新并选中、文件是否可处理、
  模式是否匹配、双签辅助证书是否选择、输出目录是否已选择。
- 需要帮助时使用界面下方的官网或技术支持入口；分享诊断信息前先确认已脱敏。
- 工具栏“更多”中提供导出诊断和打开日志；较窄窗口下，移除、重试和打开输出目录也在此菜单中。
