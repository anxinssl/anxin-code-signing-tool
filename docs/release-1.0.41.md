# 1.0.41 改版说明

日期：2026-10-22。

## 本版变更

- 软件名称统一为“安信代码签名证书工具”，版权署名为安徽斯百德信息技术有限公司。
- 第一方源码采用 GPL-3.0-only，保留第三方声明和独立商标说明。
- 标题栏、主界面和快捷方式使用官网绿色安信图标，移除右上角重复蓝色标识。
- 底部保留单个“安信官网”入口，点击进入代码签名证书页面；
  右键可复制地址。技术支持改为按钮，点击展示原企微二维码。
- 小窗口收起引导文字，保留官网和客服入口，不增加底栏高度。
- 使用 NSIS 构建 EXE 安装包，适配卸载与缓存安装包修复。
- 启动维护程序前核对安装目录、登记的产品名称、公司和版本，
  拒绝重定向目录、错误版本和不匹配的安装记录。

## 不变范围

Core、Windows、Worker 的源码保持不变。
签名引擎、证书读取、单签／双签、时间戳、文件处理和批量签名逻辑保持不变。
ViewModel 仅在 Worker 维护提示中替换八处文案，未修改控制逻辑。
脚本按固定替换表恢复旧文案后，与原文件哈希比较。
ProductionAdapters 仅将维护服务从旧 MSI 修复器切换到 NSIS 修复器；
检查脚本恢复该行后继续验证签名适配段的原始哈希。
原固定 1.0.40 目录与安装包保留。

## 从旧版本安装

1. 关闭签名工具，保留 SimplySign。
2. 在 Windows“设置 → 应用”中卸载旧的 MSI 安装版。
3. 运行新版 EXE 安装包，按界面完成安装。
4. 打开工具，刷新证书，确认显示有效证书。
5. 按原流程选择文件、模式和独立输出目录，人工验证签名。

旧 MSI 存在时，新安装器只提示迁移步骤并停止，不自动卸载旧版。
不要删除证书、待签名原文件或签名输出。
新安装器遇到文件占用会停止，不会强行结束进程。
卸载只删除明确属于产品的文件，不递归删除安装目录；无关文件会保留。

## 验证边界

自动检查覆盖源码冻结、依赖边界、离屏界面、链接及复制调用替身、维护服务、
NSIS 静态约束和隔离 QA 安装生命周期。QA 安装使用同一脚本和相同产品文件，
只替换权限、注册表、目录、快捷方式及旧 MSI 查询数据源，不使用真实证书。
正式 EXE 还要直接解包，与已测试的产品文件、许可证和源码清单逐一核对哈希。

测试不会操作当前生产安装、显示生产窗口、打开实际浏览器或执行真实签名。
Windows UAC 交互、生产安装目录权限、实际旧 MSI 卸载、实际链接显示和真实签名
需要用户人工验收。不能将自动测试表述为这些人工步骤已经完成。

## 对应源码

每次发布 EXE 必须附带同一构建快照的 source.zip。
安装目录中的 `source-manifest.json` 提供源码 ZIP 的 SHA256 和逐文件清单。
最终检查结果与安装包哈希另附交付目录，不将尚未执行的测试写成成功。
