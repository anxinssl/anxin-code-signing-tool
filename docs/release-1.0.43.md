# 1.0.43 界面易用性调整

本版修改范围仅为按钮、环境状态展示和布局，不修改证书读取、前置条件、
签名引擎、单签双签规则、时间戳处理、Worker、文件处理和批量执行。

- 常用工具栏按钮显示图标和文字，导出诊断与日志入口移入“更多”菜单。
- 较窄窗口保留添加文件、添加文件夹、刷新证书、更多和设置，
  移除、重试与输出目录入口移入菜单，不自动换行。
- 未刷新时显示待检查，刷新中显示正在检查；没有证书不再误报电脑不受支持。
- 检查失败与系统确实不符合要求分别显示，不修改底层系统支持判断。
- 刷新按钮宽度、提示区和证书区域高度不随证书内容变化。
  正常用户调整窗口尺寸时仍保留响应式适配。
- 新增展示状态只用于文案和通知，不参与签名准入判断。

自动验证使用假的证书数据及健康服务，不访问真实证书、不执行签名、
不显示生产窗口。测试对比未刷新、刷新中、有证书、无证书和检查失败时的
工具栏、证书区、文件列表、输出操作区及窗口尺寸，另检查极小窗口的文件可见性。
正式安装包需完成源码匹配、静态解包及隔离安装测试后交付。

已有 NSIS EXE 安装版可关闭工具后更新；旧 MSI 版仍需先卸载旧签名工具。
原版本保留。实际生产安装和真实签名由用户验收。
