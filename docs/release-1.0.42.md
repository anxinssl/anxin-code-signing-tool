# 1.0.42 通用证书引导

本版从已保留的 1.0.41 源码建立独立副本，仅修改云证书／UKey 引导、
证书状态文字和 SimplySign 安装前置条件。

- 主状态栏移除 SimplySign 安装状态，保留系统、签名环境、证书数量和时间戳。
- 未刷新、已读取证书、未发现证书分别显示明确状态。
- 无证书时同时提示云客户端登录及硬件 UKey 驱动、连接排查。
- SimplySign 安装状态不再决定前置检查是否成功；不新增 SafeNet 安装门槛。
- 审计不再将 SimplySign 安装检查记录为必需的成功检查；检测结果仍留在现有就绪数据中。
- 证书有效期、代码签名用途、私钥关联、主／辅助证书、文件、输出、时间戳等校验不变。
- Windows、Core、Worker、私钥调用及签名／批量执行源码不变。

自动测试使用模拟就绪状态和模拟执行器，验证缺少 SimplySign 时正常检查，
以及缺证书、缺辅助证书、无效时间戳、非法输出和格式不符时继续阻止操作。
不会访问真实证书、弹出 PIN、执行试签或操作当前安装。

1.0.41 EXE 安装版可关闭后直接运行新版安装包更新；旧 MSI 版仍需先手动卸载。
保留证书客户端、UKey 驱动、原文件和输出文件。
实际验收请重点覆盖只有 SafeNet、未安装 SimplySign 的电脑，以及原云证书场景。
不能将去掉安装门槛表述为所有 UKey 型号或所有算法已经验证兼容。
